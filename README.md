# 💻 Mi CV Interactivo (Proyecto Frontend)

Este repositorio alberga la versión interactiva de mi Currículum Vitae. Lo creé como un proyecto práctico para aplicar y solidificar mis conocimientos de desarrollo Frontend y diseño web.

El objetivo fue construir un CV moderno y responsivo, que a la vez sirviera como una prueba clara de mis habilidades.

## 🛠️ Tecnologías que Usé

* **HTML5:** Para la estructura y organización del contenido.
* **Tailwind CSS (a través de CDN):** Elegí este *framework* para practicar la metodología *utility-first* y lograr un diseño moderno y adaptable a cualquier pantalla (**responsivo**).
* **JavaScript (Librería AOS):** Implementé esta librería para manejar las animaciones de aparición (*scroll animations*), enfocándome en mejorar la experiencia visual del usuario.

## 🚀 Lo que Demuestra este Código

* **Manejo de Estilos Modernos:** No solo sé escribir HTML, sino que puedo integrarlo con una librería de estilos avanzada como Tailwind.
* **Diseño Responsivo:** El diseño funciona correctamente en teléfonos, tablets y computadoras, lo cual es fundamental para el desarrollo web.
* **Curiosidad Técnica:** Demuestra mi capacidad para investigar e incorporar librerías de terceros (AOS, Font Awesome) para enriquecer el proyecto.
